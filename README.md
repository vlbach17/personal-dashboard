# Personal Dashboard

A personal dashboard (habit tracker, quick capture, project tracker, guide database, and links to other tools) for daily/weekly use across mobile, tablet, and desktop.

See `personal-dashboard-plan.md` for the full product plan, `CLAUDE.md` for stack/conventions, and `docs/TASK_LIST.md` for current status.

## Development

```
npm install
npm run dev          # frontend only, with HMR
npm run pages:dev     # full stack incl. Cloudflare Pages Functions
npm run build
npm run deploy
```
